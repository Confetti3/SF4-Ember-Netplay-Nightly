# SF4 Ember Netplay Nightly

Daily test builds of [SF4 Ember Netplay](https://github.com/Confetti3/SF4-Ember-Netplay), made from its `nightly` branch.

Nightly builds have the newest features and may break. Players on a Nightly build can only play rooms with other Nightly players, and replays or combos saved on Nightly may not open after going back to Stable.

To use Nightly, pick **Nightly** under Settings > Updates in Ember (version 1.1.2 or later), or install a release from this repository. To go back, pick **Stable** there.

This repository holds release files only. Source code, issues and pull requests live in the main repository.
